SOLMAR is an original 3D open-world crime game set in a sun-soaked coastal city. Play seven story missions, steal cars, dodge a five-star wanted system with police chases and a police helicopter, and pick up four weapons scattered around the city. A flyable helicopter and a flyable plane, three original radio stations, a day/night cycle and weather round out a city that runs fully offline — no Rockstar names or assets anywhere, everything is original.

## Run it

```sh
node serve.ts
```

Requires Node 22. Then open http://localhost:8080 in a desktop browser.
